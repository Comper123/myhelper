# myhelper

Личный помощник на Next.js, NextAuth Credentials, PostgreSQL и Drizzle ORM. Стартовая `/` публичная; регистрация и вход доступны на `/auth/register` и `/auth/login`. Все разделы `/app` требуют авторизации, а записи привязаны к пользователю.

## Возможности

- Задачи: создание, редактирование, выполнение, удаление, сроки и привязка к календарю.
- Календари: создание тематических календарей и просмотр связанных задач.
- Привычки: создание дневных, недельных и месячных привычек, отметки выполнения по датам.
- Финансы: доходы и расходы с категориями, историей и месячным балансом.
- Заметки: создание и редактирование записей, папки, теги и поиск.

## Локальный запуск

1. Убедитесь, что PostgreSQL запущен, и создайте базу `myhelper` (например, через pgAdmin или `createdb -U postgres myhelper`).
2. Скопируйте `.env.example` в `.env.local`, укажите параметры `DATABASE_URL` и свой случайный `NEXTAUTH_SECRET`.
3. Синхронизируйте локальную схему командой `npm run db:push`.
4. Запустите приложение: `npm run dev`.

В `.env.local` секреты; этот файл игнорируется Git. Схема базы находится в `src/db/schema.ts`. Для локальной разработки `db:push` синхронизирует её с PostgreSQL.
